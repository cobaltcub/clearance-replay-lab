# Experiments

`results.json` is generated by:

```bash
python -m botlab experiment
```

`results.md` is the human-readable write-up of the run. The JSON is raw output
and should be regenerated when the lab or replay code changes; do not hand-edit
it.

The experiment is self-contained: it starts a local challenge server on a random
port, acquires a browser session, runs the replay matrix, and stops the server.
No third-party target is contacted.

For a manual run, start the lab in one terminal and use `run` or `replay` in
another:

```bash
python -m botlab lab --port 8765 --ttl 60
python -m botlab run --url http://127.0.0.1:8765/ --headed
```
